# Edge Cases

## Форма

- Пользователь отправляет форму с пустыми обязательными полями.
- Пользователь указывает некорректный телефон или неполный контакт.
- Пользователь дважды нажимает кнопку отправки и создаёт дублирующий запрос.
- Пользователь закрывает страницу во время отправки формы.

## Telegram

- Telegram API недоступен по сети.
- `TELEGRAM_BOT_TOKEN` или `TELEGRAM_CHAT_ID` не настроены.
- Telegram отвечает ошибкой валидации payload.
- Telegram доставлен, но клиент не получает мгновенное подтверждение.

## CRM

- Bitrix webhook не настроен.
- Bitrix24 возвращает HTTP-ошибку.
- Bitrix24 возвращает бизнес-ошибку в теле ответа.
- Telegram успешен, а CRM неуспешна, при этом лид уже создан.

## Чат

- Пользователь обновил страницу во время чат-сессии.
- Пользователь запрашивает оператора до завершения сценарной воронки.
- Из чата создаётся лид, но пользователь продолжает держать вкладку открытой.
- Пользователь пытается отправить сообщение в уже закрытый чат.

## WebSocket

- Дублируется событие `message:new`.
- WebSocket соединение обрывается во время набора сообщения.
- `chat:join` отправлен с несуществующим `sessionId`.
- Presence теряется после рестарта socket-server, пока клиенты не переподключатся.

## Админка

- Оператор открывает чат, который уже был закрыт другим оператором.
- Оператор отправляет пустое сообщение.
- Несколько сотрудников одновременно меняют статус одного лида.
- Пользователь делает refresh во время работы с детальной карточкой.

## Роли

- `viewer` пытается изменить статус лида напрямую через API.
- `viewer` пытается отправить операторское сообщение.
- `operator` пытается создать или редактировать пользователя.
- `admin` пытается отключить или понизить последнего активного администратора.

## База данных

- Не найдена `ChatSession`, указанная в запросе handoff.
- Не найден `Lead`, для которого отправлен PATCH статуса.
- Нарушена уникальность email при создании пользователя.
- PostgreSQL временно недоступна в момент создания лида.

## Аналитика

- UTM отсутствуют вообще.
- `NEXT_PUBLIC_YANDEX_METRIKA_ID` не задан.
- Счётчик Метрики не инициализировался на странице.
- Достижение цели не должно ломать основную бизнес-логику, если аналитика недоступна.
