# Operator Comments

## Зачем нужны комментарии менеджера

Комментарии менеджера нужны, чтобы фиксировать внутренний контекст по заявке: что уже обсуждали, какие есть договорённости, что нужно сделать дальше и какие нюансы заметил менеджер.

## Почему комментарии связаны с Lead

Комментарии напрямую связаны с `Lead`, потому что относятся к конкретной заявке и должны храниться рядом с её историей обработки. Так проще собирать весь рабочий контекст по одному лиду в одном месте.

## Поля OperatorComment

- `id` — уникальный идентификатор комментария
- `leadId` — ссылка на заявку
- `lead` — связь с моделью `Lead`
- `text` — текст комментария
- `author` — автор комментария, сейчас по умолчанию `admin`
- `createdAt` — дата и время создания комментария

## Что будет расширяться дальше

Позже комментарии будут развиваться вместе с админкой:

- пользователи
- роли
- история действий
- напоминания
