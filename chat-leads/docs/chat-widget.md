# Chat Widget

## Зачем нужен чат-виджет

Чат-виджет нужен как быстрый сценарный способ собрать заявку без большой формы. Он помогает провести пользователя по короткой продающей воронке и собрать лид в более естественном формате диалога.

## Воронка

Чат работает по логике:

- вход
- квалификация
- ценность
- контакт

## Ветки сценария

Стартовые ветки:

- `Нужен сайт + заявки`
- `Хочу чат-бот на сайт`
- `Сколько стоит`
- `Просто узнать подробнее`

Дальше сценарий ведёт пользователя по нужной ветке:

- уточняет нишу или задачу
- в некоторых ветках уточняет текущий сайт и тип заявок
- показывает блок ценности
- только после этого просит контакт

## Какие данные собираются

Чат собирает:

- `name` — фиксированное значение `Заявка из чата`
- `contact`
- `need`
- `comment`
- `source = "chat"`
- UTM-данные
- `referrer`
- `landingPage`

## Как формируется comment / summary

Поле `comment` собирается как краткая сводка диалога:

- ветка
- ниша / задача
- текущее состояние сайта
- желаемый тип заявок
- дополнительные выборы внутри сценария

Если какая-то часть сценария не использовалась, в summary подставляется `—`, а не `undefined`.

## Как создаётся Lead source=chat

`/api/lead` принимает `source` и разрешает только значения `form` и `chat`. Для виджета отправляется `source = "chat"`, поэтому заявка сохраняется в базе как лид из чата.

## Как UTM передаются из чата

Чат использует `saveUtmToStorage()` и `getStoredUtm()` из `lib/utm.ts`. Сохранённые UTM добавляются в тело запроса при отправке заявки через виджет.

## Почему контакт спрашивается после блока ценности

Контакт запрашивается только после того, как пользователь получил короткое объяснение пользы и увидел, что решение может подойти под его задачу. Это делает воронку более мягкой и повышает вероятность, что человек оставит контакт осознанно.

## Зачем нужен чекбокс политики

Перед отправкой заявки пользователь должен согласиться с политикой конфиденциальности и обработкой персональных данных. Это делает сценарий согласованным с основной формой сайта и требованиями по обработке данных.

## Какие цели Метрики используются

Для чат-виджета используются цели:

- `chat_open`
- `chat_lead_submit`
- `chat_step_select`

## Что будет дальше

Позже чат может быть расширен до полноценной системы:

- `ChatSession`
- `Message`
- WebSocket
- операторская админка
- оператор
