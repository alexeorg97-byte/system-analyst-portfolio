# Admin Filters

## Зачем нужны фильтры

Фильтры нужны, чтобы менеджер быстрее находил нужные заявки в списке, особенно когда лидов становится больше. Вместо ручного просмотра всей таблицы можно быстро сузить выборку по тексту, статусу и состоянию отправки в Telegram.

## Какие параметры поддерживаются

Страница `/admin/leads` поддерживает такие query params:

- `q`
- `status`
- `telegram`

## Как фильтры работают через query params

Фильтры работают через `GET`-форму и обычные query params в URL. Это удобно, потому что:

- фильтрованные ссылки можно открывать повторно
- параметры можно отправить коллегам
- страница остаётся серверной и не требует дополнительной клиентской логики

## Какие поля участвуют в поиске

Параметр `q` ищет совпадения по следующим полям заявки:

- `name`
- `contact`
- `need`
- `comment`
