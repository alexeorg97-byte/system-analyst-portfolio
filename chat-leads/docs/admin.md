# Admin

## Зачем нужна админка

MVP-админка нужна, чтобы быстро просматривать последние заявки из PostgreSQL без прямого доступа к базе данных. Это даёт простой внутренний интерфейс для проверки новых лидов и статусов отправки в Telegram.

## Какие страницы есть

- `/admin/login` — страница входа по паролю.
- `/admin/leads` — список последних 50 заявок.

## Как работает логин

Пользователь вводит пароль на странице входа. Пароль отправляется в `/api/admin/login`, где сравнивается со значением `ADMIN_PASSWORD` из переменных окружения. При успешной проверке сервер устанавливает `httpOnly` cookie `admin_session`.

## Почему доступ закрыт cookie

Доступ к `/admin/leads` закрыт через серверную cookie, потому что это простой и достаточный способ для MVP-защиты внутренней страницы. `httpOnly` cookie нельзя прочитать из клиентского JavaScript, поэтому такой подход безопаснее, чем хранить флаг авторизации на клиенте.

## Какие данные отображаются в списке заявок

В списке заявок показываются:

- дата создания
- имя
- контакт
- что нужно
- комментарий
- статус
- флаг успешной отправки в Telegram
