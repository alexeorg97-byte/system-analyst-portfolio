# Analytics

## Зачем нужна Яндекс Метрика

Яндекс Метрика нужна, чтобы понимать, как пользователи взаимодействуют с сайтом Chat Leads: откуда они приходят, какие CTA нажимают и доходят ли до успешной отправки заявки.

## Какая env-переменная используется

Для подключения счётчика используется переменная окружения:

- `NEXT_PUBLIC_YANDEX_METRIKA_ID`

Если она не задана, скрипт Метрики не подключается.

## Какие цели реализованы

Сейчас реализованы такие цели:

- `lead_form_submit`
- `thanks_page_view`
- `lead_success`
- `cta_click`

## Где именно вызываются цели

- `lead_form_submit` — после успешной отправки формы заявки, перед переходом на `/thanks`
- `thanks_page_view` — при открытии страницы `/thanks`
- `lead_success` — при открытии страницы `/thanks`
- `cta_click` — при клике по основным CTA-кнопкам публичного лендинга

## Как это помогает анализировать воронку

Такая настройка помогает видеть базовую воронку:

- пользователь нажал на CTA
- пользователь отправил форму
- пользователь дошёл до страницы успеха

Это позволяет сравнивать трафик и конверсию по источникам, CTA и рекламным кампаниям.
