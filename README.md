# Кейсы

## 1. Migration Assistant Bot

Чат-бот для автоматизации взаимодействия с клиентами: консультации, продажа цифровых продуктов, предоплата, передача заявок в CRM и уведомления менеджерам.

**Роль:** системный аналитик  
**Фокус:** чат-бот, сценарии, платежи, CRM-интеграция  
**Стек и инструменты:** Python, Telegram Bot API, YooKassa, Bitrix24 CRM, REST/webhooks, JSON, BPMN, UML, ERD

Что прорабатывалось:

- сценарный чат с ветвлением
- продажа цифровых PDF-продуктов
- предоплата через YooKassa
- передача заявок в Bitrix24
- Telegram-уведомления менеджерам
- API/webhook-логика
- edge cases и ошибки оплаты/интеграций

[Подробнее о кейсе →](./migration-assistant-bot/README.md)

## 2. Chat Leads

Production-прототип lead management системы с сайтом, формой заявки, чат-ботом, real-time чатом с оператором, админкой, ролями, аудитом, Telegram-интеграцией, UTM-трекингом и аналитикой.

**Роль:** системный аналитик + разработчик/интегратор  
**Фокус:** lead management, real-time chat, админка, API/WebSocket, роли, аудит  
**Стек:** Next.js, TypeScript, PostgreSQL, Prisma, Socket.IO, Telegram Bot API, Яндекс Метрика, Nginx, PM2, VPS

Рабочий прототип: https://chat-leads.ru  
Публичный кейс: https://chat-leads.ru/case

Что реализовано и спроектировано:

- лендинг и форма заявки
- сохранение Lead в PostgreSQL
- Telegram-уведомления
- админка заявок
- статусы, комментарии, история событий
- IntegrationLog
- UTM tracking и цели Метрики
- ChatSession и Message
- bot-to-operator handoff
- real-time чат через Socket.IO
- User / роли admin, operator, viewer
- AuditLog
- production-деплой на VPS с HTTPS
- формальная документация: ERD, OpenAPI, WebSocket contract, тест-кейсы, НФТ, backlog

[Подробнее о кейсе →](./chat-leads/README.md)
