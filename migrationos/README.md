# MigrationOS — платформа миграционного сопровождения

MigrationOS — B2B/B2C/back-office платформа для автоматизации миграционного сопровождения иностранных работников, взаимодействия с работодателями и внутренней работы агентства.

## Контекст

- агентство ведёт иностранных работников;
- процессы раньше выполнялись вручную: Excel, мессенджеры, проверки на сайтах МВД;
- цель платформы — объединить документы, заявки, проверки, уведомления, платежи, чаты и аналитику рисков в одной системе.

## Моя роль

Роль: системный аналитик.

Зоны ответственности:

- анализ и декомпозиция требований;
- описание пользовательских и системных сценариев;
- проектирование ролевой модели и матрицы прав доступа;
- описание бизнес-процессов;
- проектирование модели данных;
- описание REST API и webhook-интеграций;
- проработка статусных моделей;
- описание edge cases;
- подготовка acceptance criteria, тест-кейсов и чек-листов.

## Пользователи системы

- Мигрант;
- Работодатель;
- Менеджер агентства;
- Руководитель агентства;
- Superadmin.

## Основные модули

- Мобильное приложение мигранта;
- Личный кабинет работодателя;
- Административная панель агентства;
- Маркетплейс услуг;
- Core/backend;
- Лендинг.

## Ключевые интеграции

- SHERPA RPA / РКЛ-робот;
- 1С;
- СБП / платежный шлюз;
- FCM push-уведомления;
- S3-хранилище;
- Email / transactional notifications.
