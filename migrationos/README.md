# MigrationOS — платформа миграционного сопровождения

**MigrationOS** — B2B/B2C/back-office платформа для автоматизации миграционного сопровождения иностранных работников, взаимодействия с работодателями и внутренней работы агентства.

Проект объединяет мобильное приложение мигранта, личный кабинет работодателя, административную панель агентства, маркетплейс услуг, Core/backend-сервисы, интеграции с внешними системами, уведомления, платежи и аналитику рисков.

---

## Контекст проекта

Агентство занимается миграционным сопровождением и аутстаффингом иностранных работников. До внедрения платформы часть процессов выполнялась вручную:

- учет сотрудников и документов в таблицах;
- коммуникация через мессенджеры;
- ручной контроль сроков патентов, регистраций и других документов;
- проверки по государственным реестрам;
- обработка заявок и запросов без единого статуса и прозрачного трекинга;
- разрозненная коммуникация между мигрантами, работодателями и менеджерами агентства.

Цель MigrationOS — объединить документы, заявки, проверки, уведомления, платежи, чаты, аналитику рисков и внутренние процессы агентства в единой цифровой платформе.

---

## Моя роль

**Роль:** системный аналитик.

Зоны ответственности:

- анализ и декомпозиция бизнес-требований;
- описание пользовательских и системных сценариев;
- формализация функциональных и нефункциональных требований;
- проектирование ролевой модели и матрицы прав доступа;
- описание бизнес-процессов и статусных моделей;
- проектирование модели данных и основных сущностей;
- описание REST API и webhook-интеграций;
- проработка edge cases, ошибок и fallback-сценариев;
- подготовка acceptance criteria, тест-кейсов и чек-листов приемки;
- согласование логики между интерфейсом, backend, интеграциями и бизнес-процессами.

## Пользователи системы

| Роль | Описание |
|---|---|
| **Мигрант** | Иностранный работник. Использует мобильное приложение для документов, уведомлений, заявок, услуг и коммуникации с агентством. |
| **Работодатель** | Компания-клиент агентства. Видит только своих мигрантов, контролирует документы, обрабатывает запросы и заказывает услуги. |
| **Менеджер агентства** | Сотрудник агентства. Обрабатывает мигрантов, документы, заявки, запросы, чаты и задачи. |
| **Руководитель агентства** | Контролирует процессы, аналитику, риски, проекты, менеджеров и финансовые показатели. |
| **Superadmin** | Администратор системы. Управляет техническими настройками, пользователями, ролями и справочниками. |

## Основные модули

| Модуль | Назначение |
|---|---|
| **Мобильное приложение мигранта** | Профиль, документы, загрузка сканов, уведомления, запросы, услуги, чат, электронная подпись. |
| **Личный кабинет работодателя** | Дашборд рисков, список своих мигрантов, заявки, запросы от мигрантов, счета и платежи. |
| **Административная панель агентства** | Управление мигрантами, работодателями, проектами, документами, заявками, запросами, задачами, чатами и аналитикой. |
| **Маркетплейс услуг** | Каталог услуг для мигрантов и работодателей, анкеты, трекинг, оплата, счета. |
| **Core/backend** | Авторизация, роли, документы, уведомления, заявки, платежи, РКЛ-проверки, аналитика, чаты, audit log. |
| **Лендинг** | Публичная точка входа для мигрантов и работодателей, описание услуг, FAQ, форма заявки, AI-чат-бот. |

## Ключевые интеграции

| Интеграция | Назначение |
|---|---|
| **SHERPA RPA / РКЛ-робот** | Прием результатов проверки по Реестру контролируемых лиц и обновление риск-статусов. |
| **1С** | Синхронизация данных по сотрудникам, работодателям и внутренним учетным данным. |
| **СБП / платежный шлюз** | Онлайн-оплата услуг, webhook статусов платежей, генерация счетов. |
| **FCM push-уведомления** | Push-уведомления мигрантам на RU / UZ / EN. |
| **S3-хранилище** | Безопасное хранение сканов документов и сгенерированных PDF. |
| **Email / transactional notifications** | Уведомления работодателям, менеджерам и клиентам по email. |

## Что показывает этот кейс

Этот кейс демонстрирует:

- умение работать с комплексной B2B/B2C/back-office системой;
- понимание пользовательских, бизнесовых и системных сценариев;
- проработку ролей, прав доступа и ограничений видимости данных;
- умение описывать требования, acceptance criteria и edge cases;
- понимание REST API, webhook-интеграций и асинхронных событий;
- умение проектировать модель данных, сущности, связи и статусные модели;
- понимание интеграций с внешними системами: РКЛ-робот, 1С, платежи, push, S3;
- навык подготовки тест-кейсов, чек-листов и приемочных сценариев;
- способность связывать интерфейсную логику, backend, данные и бизнес-процессы в единую систему.
